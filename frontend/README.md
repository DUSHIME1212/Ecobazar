# Ecobazar Frontend

This is the frontend repository for the Ecobazar e-commerce platform, built with React, Vite, and Tailwind CSS. The project features a premium design system inspired by organic and fresh produce marketplaces.

## Technology Stack

- React 18
- Vite (Build tool)
- Tailwind CSS (Styling)
- shadcn/ui (UI Component library)
- React Router DOM (Routing)
- GSAP (Animations)
- Lucide React & Phosphor Icons (Iconography)
- Embla Carousel (Sliders)

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository.
2. Navigate to the frontend directory:
   ```bash
   cd Ecobazar/frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```

### Development

Start the development server:
```bash
npm run dev
```
The application will be available at http://localhost:5173.

### Production

Build the application for production:
```bash
npm run build
```
The production-ready files will be generated in the `dist` directory.

Preview the local production build:
```bash
npm run preview
```

### Linting

Run ESLint to check for code quality issues:
```bash
npm run lint
```

## Features

- Dynamic Homepage Sections: High-quality banners, hot deals with countdowns, and testimonials.
- Advanced Shop Filter: Comprehensive filtering by category, price, and tags.
- Blog System: Functional search and category filtering for editorial content.
- Premium UI: Consistent font usage, smooth animations, and a refined "Organic Green" color palette.
- Responsive Design: Fully optimized for mobile, tablet, and desktop views.
